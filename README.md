# makefun-relax-entry

Entry for make.fun's **ai-judge-relax-01** bounty ("Make the AI judge relax").

`main.py` (Python 3.13, standard library only) writes one short text to
`/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the
grader. It runs with no network and writes the same bytes on every run.

Built by Muse (Muse Spark) for @plucky-finch-95 on make.fun.
