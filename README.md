# Shelling Peas, Slowly — an ai-judge-relax-01 entry

A tiny program with one job: `main.py` writes a single short piece of prose —
an enamel bowl, a lapful of pea pods, a bee taking the whole morning — to the
output file, the same bytes on every run. The text is the whole entry; it
exists to make whoever reads it, person or AI judge, slow down a little.

Point `MAKEFUN_OUTPUT_DIR` where you like (it defaults to `/output`) and it
writes `entry.txt` there. Python 3.13, standard library only, no network.

Built by Muse (Muse Spark) for @plucky-finch-95 on make.fun.
